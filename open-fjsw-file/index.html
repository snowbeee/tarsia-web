How to open an .fjsw file

An .fjsw file is a jigsaw made in Formulator Tarsia. You can open one here, in this browser tab, on any computer — including the ones the desktop app will not run on. The file is read on your own machine and is never uploaded.

Open an .fjsw file

What the file actually is

Formulator Tarsia, a free Windows program from Hermitech Laboratory, saves each puzzle as one .fjsw file. Inside, it is XML: the template the puzzle uses, the question and answer pairs, and any equations, stored as MathML. That is the whole reason this page can exist — the format is readable, so a browser can be taught to read it.

If you search for this, you will mostly find sites telling you that .fjsw cannot be converted and that you must install the desktop app, or offering to convert it for you if you upload it first. Neither is necessary.

Opening one

  • Open the puzzle maker.
  • Press Open… and choose your .fjsw file.
  • The puzzle is drawn on screen, with its questions and answers in an editable list beside it.
  • Download PDF gives you the pieces to cut out and a matching answer sheet.

Nothing is installed and no account is made. The whole thing is a static web page, so once it has loaded it will keep working with the network switched off.

Which puzzles it can draw

These templates are laid out and verified against real files:

  • Standard hexagonal jigsaw — 24 triangles tiled into a hexagon.
  • Extended hexagonal jigsaw — the same hexagon, with the 12 outer edges filled with decoy answers instead of left blank.
  • Standard triangular jigsaw — 16 triangles in a large triangle.
  • Dominoes — a chain of any length.
  • Matching rectangular cards — a two-column grid of any size.

Two more are drawn from a shape that was reconstructed rather than confirmed: the 4×4 square jigsaw and the parquet rosette. Both the screen and the exported PDF say so plainly, so you find out before the photocopier rather than after it.

A file using any other template still opens. Its questions and answers are read correctly and you are told there is no layout for that shape yet — from there you can pour the content into one of the shapes above and print that instead. A file you cannot open is a file you have lost; that was the thing worth avoiding.

What does not survive the trip

Equations become text. MathML is flattened to plain characters on import, so a simple expression comes through fine and a heavily typeset one will want checking before you print it.

There is no save back to .fjsw. Save writes a .tarsia.json file that this app reads back. Writing the original format again would mean rebuilding the MathML that was just flattened, which would quietly degrade the file rather than preserve it — so it is not offered at all.
