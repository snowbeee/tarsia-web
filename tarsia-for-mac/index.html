Tarsia puzzles without Windows

Formulator Tarsia is a Windows program, and there has never been a Mac build. This is the same kind of tool as a web page: it makes the same cut-out puzzles, opens the .fjsw files you already have, and prints them — from a Mac, a Chromebook, an iPad or a Linux machine.

Make a puzzle

The usual ways round it, and what they cost

Teachers have been solving this for years, and all the solutions work. They are just expensive in a way that is easy to underestimate when the thing you want is one worksheet.

  • A virtual machine — Parallels, VMware or UTM, plus a Windows licence. Reliable, and the most expensive option in both money and disk space.
  • Wine or CrossOver — free or cheap, and often works, but it is an afternoon of configuration that tends to need repeating after a major macOS update.
  • The school's one Windows machine — fine until you want to change a question the evening before the lesson.

None of them are available at all on a managed Chromebook or an iPad, which is what a growing number of schools actually hand to staff.

What this does instead

It is a web page, so there is nothing to install and no device policy to get round. Open it, type your question and answer pairs, choose a shape, and download a PDF of the pieces and the answer sheet. If you already have .fjsw files, press Open… and they are drawn from the file — see opening an .fjsw file for which templates are supported.

Everything happens inside the browser. Your file is read on your own machine, the layout is computed there and the PDF is built there; nothing is uploaded, and after the first load the page works offline.

Where it is better, and where it is not

Better

  • Runs on every machine a teacher is likely to be given.
  • Offers puzzle sizes the desktop app never had — triangles from 4 to 36 pieces, hexagons from 6 to 54, square grids, domino chains and matching cards, all generated rather than drawn from a fixed list.
  • Outside edges can be labelled with decoys on any tiled shape, not only on the one template that came with it.
  • Nothing leaves your computer.

Not better

  • It does not write .fjsw files. It saves its own .tarsia.json instead, so a puzzle made here cannot be handed back to a colleague still using the desktop app.
  • Equations in an imported file are flattened from MathML to plain text, so heavily typeset maths will need a look before printing.

For most people the trade is worth making: a department's existing files stay usable, and new puzzles can be made on whatever is to hand.
